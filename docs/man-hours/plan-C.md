# 案C: 工程ごとの積み上げ

- 状態: 提案。工程テンプレート・工程時間は整備士による確認前
- 共通定義: [体系化計画・入力辞書](README.md)

## 1. 方針

作業を準備・脱着・交換／修理・調整・確認等の工程に分け、各工程の人数と実作業時間を入力して合計する。基準工数がない作業や、追加作業を個別に説明したい場合に使う。

工程の例は入力体系を考えるための候補。実際の整備手順、必要な設備、安全上の判断は整備士が確認する。

## 2. この案で追加する入力

| 項目 | 必須度 | 形式・単位 | 取得先・確認事項 |
|---|---|---|---|
| `template_id` 工程テンプレート・版・確認者 | 使用時必須 | ID、版、担当者 | 対象の車両仕様・作業で使えるか整備士が確認する |
| `operation_id` 工程ID・内容・含有範囲 | 算出時必須 | ID、説明 | 工程の漏れと重複を確認する |
| `workers` 人数または作業者別の時間明細 | 算出時必須 | 人、明細 | 複数人の作業時間が異なる場合は作業者別に記録する |
| `active_minutes` 実作業時間の下限／上限・確定値 | 算出時必須 | 分 | 整備士の見積もりまたは確認済み実績。出所を併記する |
| `time_basis` 時間の根拠・仮定 | 算出時必須 | 参照ID、説明 | 計測値・事後申告・暫定見積もりを区別する |
| `waiting_minutes` 待機時間・拘束の有無 | 該当時必須 | 分、選択値 | 部品待ち等を実作業と区別する |
| `dependencies` 前提工程・並行可否 | 納期も出す場合に必要 | 工程ID、選択値 | 経過時間の計画に使う。人時の合計とは別計算にする |
| `extra_operations` 状態により発生する工程 | 該当時必須 | 工程ID、発生条件 | 未確認状態は、工程なしと確定しない |
| `shared_operation_id` 同時作業間で共有する工程 | 該当時必須 | 共通ID、配分先 | 見積もり全体で1回だけ計上し、内訳への配分を記録する |

## 3. 算出と不足情報の扱い

同じ時間だけ作業する工程では、`工程人時 = 人数 × 実作業分数 ÷ 60`。作業者ごとの時間が異なる場合は、各作業者の実作業分数を合計して60で割る。

`見積もり全体の人時 = 重複を除いた工程人時の合計`

- 追加工程を含む場合と含まない場合の前提を示し、整備士が下限・上限を確認する。
- 工程の時間に根拠がない場合は、AIが埋めず「要見積もり」とする。部分合計を完成した見積もりとして扱わない。
- 待機中に作業者を拘束する場合、その扱いは工場の方針を確認し、課金理由を残す。
- 納期・経過時間を求める場合は並行関係と待機を考慮する。人時の合計をそのまま完了までの時間として提示しない。
- Aから切り替える場合は、基準人時を含めず工程の合計で算出する。基準人時と全工程を二重に足さない。

## 4. 実施計画

1. 対象作業を1つ選び、整備士と必要工程・含有範囲を整理する。
2. 通常工程と状態に応じた追加工程を整理し、同時作業で共有する工程に共通IDを付ける。
3. 各工程の人数・実作業分数・待機・根拠を入力できる票を作る。テンプレートによる初期値は整備士の確認後に使用する。
4. 1人作業、2人作業、共通工程あり、時間不明の入力例で人時と経過時間の違いを確認する。
5. 作業後に工程別の実績と見積もりとの差を記録し、工程テンプレートを見直す。

成果物は「工程テンプレート」「工程別入力票」「共有工程・配分表」「工程別実績」。採用条件は、整備士が工程の漏れ・重複を確認でき、入力負担が許容できること。

## 5. 表示例（計算説明用の架空値）

| 工程 | 人数 | 1人あたりの実作業時間 | 人時 |
|---|---|---|---|
| 共通準備 | 1人 | 15分 | 0.25 |
| 脱着 | 2人 | 15分 | 0.50 |
| 交換作業 | 1人 | 30分 | 0.50 |
| 確認 | 1人 | 15分 | 0.25 |
| 合計 | — | — | 1.50 |

すべて順番に行う仮定なら、待機なしの経過時間は75分だが、人時は1.50。共通準備を別の作業にも使用する場合は、見積もり全体で0.25人時を1回だけ計上する。これは実作業の手順・所要時間の推奨ではない。

## 6. 取得ソースの調査結果（2026-10-11）

詳細・URL・アクセス条件は[ソース調査](data-sources.md)を参照する。

| 入力 | 取得候補 | 取得の条件・残る不足 |
|---|---|---|
| 工程・対象仕様・設備 | MH03 FAINES整備マニュアル＋MH12 整備士 | 契約・対象車両・版・利用範囲を確認。一般公開の諸元表は整備手順を提供する資料ではない |
| 作業範囲・重複工程 | MH01 日整連の公開説明、MH11 作業指示書 | 公開説明で重複控除の考え方を確認。工程への適用は整備士が確認する |
| 工程の参考情報・待機の存在 | MH10 店舗公式の防錆工程紹介 | 洗車・養生・塗装・乾燥の説明あり。工程別人時は得られず、乾燥と実作業を区別する |
| 人数・工程別実作業分数・待機 | MH12 作業者別計測、MH11 日報 | 現場の収集が必要。基準点数を工程へ均等に割り振らない |

最初は1作業の適合マニュアルを整備士が確認し、工程一覧を作る。各工程の人数・開始／終了・中断を計測し、追加工程と共通工程を対応づける。公開記事の合計時間を各工程の実測値として扱わない。

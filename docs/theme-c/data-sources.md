## 取得・利用時のメモ

### W01：過去の気象データ・ダウンロード

- 範囲・期間：出店・店舗所在地の近隣観測地点。地点と要素によって取得期間が異なる。
- 取得方法：画面で地点・要素・期間・品質情報を選択し、必要な範囲だけCSVを取得。
- 利用条件：出典・加工を表示し、個別条件も確認（[公式の条件・案内](https://www.jma.go.jp/jma/kishou/info/coment.html)）。
- 注意点：品質情報を残す。欠測を0扱いしない。当別町内の全地点・全要素があると仮定せず、距離と観測項目で地点を選ぶ。過度な自動アクセスを避ける。

### P01：行政区別住民基本台帳人口

- 範囲・期間：当別町内。2026年10月1日現在の資料へのリンクを確認。
- 取得方法：対象月のPDFから行政区・人口・世帯を確認。数値化時は原表と照合。
- 利用条件：一般ページに一律のオープンライセンスは確認していない。資料の転載・再配布条件は個別確認（[公式の条件・案内](https://www.town.tobetsu.hokkaido.jp/soshiki/ict/exclusion.html)）。
- 注意点：住民数は昼間人口・来客数ではない。行政区と国勢調査の小地域を同一視しない。国勢調査と混ぜる場合は定義・基準日を示す。

### P02：国勢調査・経済センサスの統計データ／境界データ

- 範囲・期間：北海道→当別町、目的の人口・年齢・世帯・事業所表と公表年を選ぶ。
- 取得方法：統計名→年→集計単位→北海道で検索。統計表と同じ年・区画の境界を取得。
- 利用条件：出典・加工を表示。統計GISの個別規約と選択データの条件も確認（[公式の条件・案内](https://www.e-stat.go.jp/terms-of-use)）。
- 注意点：市町村表が最新でも同年の小地域表が公開済みとは限らない。KEY_CODE等は文字列。秘匿値を0扱いせず、同じ人口を複数集計しない。

### T01：令和3年度 全国道路・街路交通情勢調査

- 範囲・期間：北海道、当別町周辺の対象路線・観測箇所を選択。2021年度の過去調査。
- 取得方法：「2. 箇所別基本表及び時間帯別交通量表」→北海道。ヘッダ説明と用語定義も読む。
- 利用条件：省の利用案内と個別データの条件を確認し、調査名・年度・加工を表示（[公式の条件・案内](https://www.mlit.go.jp/link.html)）。
- 注意点：当日・現在の交通量ではない。道路通過台数を歩行者数・客数・修理件数に置き換えない。12時間・24時間、車種、上下方向を区別する。

### T02：当別ふれあいバスのGTFSデータ

- 範囲・期間：当別ふれあいバス。2026年4月1日改正版へのリンクを確認。
- 取得方法：公式ページの最新版ZIPを取得。feed_info、calendar、calendar_dates等がある場合は適用期間・例外日を確認。
- 利用条件：当該GTFSはページにCC BY 4.0の表示あり。一般の町資料にこの許諾を広げない（[公式の条件・案内](https://www.town.tobetsu.hokkaido.jp/site/fureai-bus/33942.html)）。
- 注意点：予定ダイヤであり、実際の乗客数・遅延・現在位置ではない。24:00を超える時刻や予約便の条件を確認。ZIP中身の検証は未実施。

### T03：当別町地域公共交通計画

- 範囲・期間：当別町。2024年12月25日変更版へのリンクを確認。
- 取得方法：「現状と課題」「資料編」から必要な図表と調査年月・対象を確認。
- 利用条件：資料ごとの権利・転載条件を確認。引用時は図表名・ページ・調査年を表示（[公式の条件・案内](https://www.town.tobetsu.hokkaido.jp/soshiki/ict/exclusion.html)）。
- 注意点：計画の目標と実績を区別。特定日の調査や回答者の標本から町全体や今の人流を断定しない。

### G01：地理院タイル

- 範囲・期間：当別町を含む地図。種類により範囲・作成年が異なる。
- 取得方法：タイル一覧から必要な背景地図を選び、仕様に従って表示。
- 利用条件：出典表示と種類別条件に従う。保存画像・印刷・第三者タイルは利用方法に応じて確認（[公式の条件・案内](https://maps.gsi.go.jp/help/use.html)）。
- 注意点：地図は人口・人流データではない。座標系と緯度経度の順序を合わせる。住所変換API・経路APIがあると仮定しない。

### F02：小売物価統計調査（動向編）

- 範囲・期間：目的品目・調査都市・年を選択。当別町の直接観測価格と仮定しない。
- 取得方法：表の地域と銘柄・数量単位を確認し、利用可能な都市・月を選ぶ。
- 利用条件：出典・加工を表示し、個別表の条件を確認（[公式の条件・案内](https://www.e-stat.go.jp/terms-of-use)）。
- 注意点：地域や銘柄が違う価格を比較しない。実仕入額・実見積額・工場の工賃を置き換えない。

### F03：石油製品価格調査

- 範囲・頻度：給油所小売（ガソリン・軽油・灯油）、民生用灯油（給油所以外）、産業用（軽油・A重油）、卸（ガソリン・軽油・灯油）。週次／月次は選択した調査の案内を確認する。
- 取得方法：公式ページで調査を選び、北海道を含む地域・油種・期間を指定した公表表を取得。店頭／配達などの区分、調査日、税込・税抜、円/L・円/18L等の単位を記録する。個別ファイルの形式・列は取得時に確認。
- 利用条件：提供元の利用規約と各表の注記を確認し、調査名・地域・調査日・加工を表示。
- 注意点：小売・卸・産業用は別の取引段階。民生用灯油の価格を工場の大口納入価格として使わない。この調査の掲載油種にナフサ価格は含まれていないため、F06・F07で別に追う。

### F04：北海道における石油製品情報（価格・需給）

- 範囲・頻度：道内の灯油・ガソリン・軽油の価格と月末在庫量は毎月更新。地域別灯油価格は道北・道央・道東・日勝・道南の5地域で、需要期の10月〜翌3月に毎週公表する案内を確認。
- 取得方法：公式ページから月次のExcel／PDF、地域別灯油価格の表・推移グラフを選ぶ。過去分は[バックナンバー](https://www.hkd.meti.go.jp/information/keizai/index_back.htm)を参照。当別周辺の比較候補は道央とし、対象市町村・調査対象・配送条件は原表で確認。
- 利用条件：局と原調査の提供元の条件・注記を確認。複数機関の調査を取りまとめた資料なので、引用する系列の元の出典も残す。
- 注意点：更新月と価格の対象月を区別し、冬季の週次系列を通年系列と仮定しない。F03と同じ原調査を含む場合は独立した観測として二重集計しない。

### F05：北海道電力の燃料費調整単価等

- 範囲・頻度：低圧、高圧・特別高圧の適用月別単価。工場が北海道電力と契約している場合に、供給区分・料金プランに合う資料を選ぶ。
- 取得方法：公式の過去一覧から対象月のPDFを取得し、燃料費調整単価等（円/kWh）、適用月、支援による値引きの扱い、税込・税抜を確認する。
- 利用条件：提供元の掲載資料の転載・加工条件を確認し、資料名・適用月・対象契約を表示。
- 注意点：調整単価は電気料金の一部。基本料金・電力量料金・再エネ賦課金等を合わせて請求書と照合する。他社契約にはその会社の料金資料を使う。工場全体の電力使用量を暖房使用量と同一視せず、暖房分を分離できない場合は電気代全体の比較とする。

### F06：日本銀行の企業物価指数

- 範囲・頻度：企業間で取引される財の月次価格指数。国内・輸出・輸入の区分と、円ベース／契約通貨ベースを区別する。
- 取得方法：[品目分類・ウエイト等の関連資料](https://www.boj.or.jp/statistics/outline/exp/pi/cgpi_2020/index.htm)でナフサ・潤滑油・塗料・シンナー・タイヤ等に対応する品目と公表可否を確認し、時系列検索で利用可能な系列・期間を選択。複数系列の収集には[一括ダウンロード](https://www.stat-search.boj.or.jp/ssi/docs/info/dload.html)も候補とする。採用した系列コード・正式名称・基準年・速報／訂正の状態を保存。
- 利用条件：日本銀行の利用案内と系列注釈を確認し、指数名・系列・基準年・対象月・加工を表示。
- 注意点：指数は円/L等の金額ではない。基準改定・接続指数・品質調整に注意し、前月比／前年同月比は同じ系列で比較する。ナフサなどの原料指数の変化率を、そのままオイル・塗料・タイヤの仕入単価に適用しない。対応品目が非公表の場合は上位分類による参考比較と明記。

### F07：財務省貿易統計によるナフサ等の輸入単価

- 範囲・頻度：全国の統計品目別の月次輸入金額・数量。北海道や当別の工場の購入価格ではなく、輸入段階の参考指標。
- 取得方法：「統計品別表」「統計品別推移表」で輸入・対象年月・品目を選ぶ。対象年の輸入統計品目表でナフサ等の対象範囲と9桁コードを確認して記録し、金額・数量を取得。ナフサに相当する細分コードの選定・実データ取得は未実施。
- 計算方法：単位を確認して `輸入金額 / 輸入数量` を求める。例えば金額が千円、数量がkLなら `金額 × 1,000 / 数量` が円/kL。複数国・品目を合わせる場合は金額合計を数量合計で割り、単価の単純平均にしない。数量0・欠測の場合は計算しない。
- 利用条件：[利用上の注意](https://www.customs.go.jp/toukei/sankou/howto/riyou.htm)と掲載データの利用条件を確認し、品目コード・輸入区分・対象月・速報／確報・算式を表示。
- 注意点：輸入単価は品目構成や輸入国構成の変化でも動く。国産ナフサ価格、スポット価格、工場が購入する溶剤等の製品価格とは区別する。コードの改訂・数量単位の違いを確認し、重量から容量への換算は根拠のある密度がなければ行わない。

### 暖房費・仕入価格の継続収集と比較

- まず工場の暖房方式と実際の購入品目・規格を確認する。「ナフサ」は原料指標として追うのか、工場が直接購入する製品なのかを確認し、購入製品の仕入履歴と対応づける。
- 収集の目安は灯油の週次（F03・冬季のF04）、電気料金調整・原材料指数・輸入統計の月次（F05〜F07）、実仕入単価と仕入先の価格改定通知は納入・改定ごと。公表遅れや訂正を考慮し、対象期間と取得日を別々に記録する。
- 暖房費は単価と使用量を分けて比較し、気温・暖房時間・設備の違いも記録する。同じ使用量を置いた単価差の試算と、実際の請求額の増減を区別する。
- 仕入価格は同じ品番・規格・容量・税・送料条件で前回比／前年同月比を比較する。外部指標は値上がりの背景確認に使い、正式見積には事業者が確認した実仕入単価を使う。

### V01：自動車保有台数

- 範囲・期間：北海道の背景統計。町別詳細が無料公開されるとは仮定しない。
- 取得方法：公開表の対象日と車種を確認。有料統計書の購入は今回の準備に含めない。
- 利用条件：転載・加工等は協会の条件を個別確認。引用の出所を記す。自由再配布データとして同梱しない（[公式の条件・案内](https://www.airia.or.jp/about_site.html)）。
- 注意点：車両保有数は入庫台数・故障件数ではない。一般統計から個別車両の整備要否を決めない。

## 実装時の結合と引用

- 日付はAsia/Tokyo。時刻付き売上と日別気象を合わせる場合、集計の意味を明記する。
- 地域・地点を対応させる。行政区、国勢調査小地域、道路区間、駅、停留所は別の単位。緯度経度・基準年・境界の版を確認する。
- 人口は居住者、道路交通量は車両、駅乗降は駅利用、GTFSは予定運行。歩行者や来客の実測値は今回のリストでは確保していない。
- 道路調査のCSVリンクは掲載を確認したが、ブラウズツールでは実ファイルを読めなかった。ヘッダ・文字コード・当別周辺の該当行は取込時に検証する。2021年度を最新調査と断定しない。
- 国勢調査は公表段階が粒度によって異なるので、利用する表の年・地域を選び、ダウンロード日を記録する。現時点の人口数をこの資料に固定しない。
- 原本は別に保持し、出典ID、実際の取得URL、取得日時、対象期間、地域、単位、品質、利用条件、原本SHA256、加工・除外を記録する。
- 表・地図・出力には「出典：提供者『データ名』、対象期間・地点、URL、取得日」「当チームが集計・加工」を表示する。source-register.jsonの確認日を実データの取得日として流用しない。
- 個別データの取得URL・ファイル版を確認してから引用する。公開ページの存在だけでAPI、リアルタイム更新、無制限利用を保証しない。

## 利用条件や取得が難しい場合

人口の細かな地域データが取れなければ、市町村単位の背景説明まで縮小する。交通・人流が取れなければ場所と曜日の実績比較やアクセス案内にとどめる。外部データなしで成り立つ中心機能を優先し、数値の推測補完で穴を埋めない。
